## Original author

[decryphe](https://github.com/decryphe) created the desktop segmentator and the Python extractor. This repository is developed from that work:

- [yolo-segmentator](https://github.com/decryphe/yolo-segmentator) (Rust / egui)
- [yolo-extractor](https://github.com/decryphe/yolo-extractor) (frame sampling and augmentation)

**cguerreroto** built on that work to form the current pipeline and keeps developing it in this repository.
